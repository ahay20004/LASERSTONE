# LASERSTONE — Parallel Preview and Scientific Agent Council Plan
Status: planning document. No public deployment, live agent service, or patent filing is asserted.

## A. Controlled public preview
- Arabic and English only; test RTL, responsive layout, keyboard access and language fallback.
- Publish only approved informational content and synthetic examples.
- Review CSP, static assets, repository history, third-party licenses, privacy language, IP exposure and logo clearance.
- Keep authentication, private datasets and simulation services disabled in phase one.
- Gate: recorded technical checks, IP/security review, explicit owner approval. Deployment is separate.

## B. Scientific Agent Council pilot (read-only)
- Coordinator routes reviews, tracks disagreements and prepares owner decisions.
- Physics/laser, chemistry/plant, software/measurement quality, IP/safety and independent critic roles.
- Every review reports claim, evidence, provenance, uncertainty, assumptions, objections, next tests and NOT_VERIFIED where appropriate.
- No agent may merge, spend, publish, access private files by default or certify legal/medical safety.
- Gate: documented trial on LS-PDC-001, evaluation of contradictions and hallucinations, owner approval.

## C. Plant-analysis device feasibility
- Decide whether targets are elements, organic compounds or optical classification.
- Compare UV-Vis/fluorescence, Raman and LIBS against the target and matrix.
- Specify reference methods, calibration, uncertainty, repeatability and safety.
- Costs and performance remain UNKNOWN until supported by quotes or measurements.
- No laser hardware operation without qualified safety review.
- Gate: owner approval of requirements and comparison before detailed design.

## D. Intellectual property screening
- Store confidential invention disclosures outside public GitHub.
- Check prior art, ownership, inventorship, licensing and historical public disclosures.
- Do not assume each software module or scientific idea is patentable.
- Consult qualified Saudi IP professionals on filing and disclosure timing.
- Gate: written publication clearance per asset and separate filing decision per invention.

## Shared governance
Weekly checkpoint: evidence, blockers, risks, cost and decision needed for A/B/C/D.
Decisions: APPROVE / REVISE / DEFER / REJECT.
All releases require independent approval and evidence.

## Verification checklist
- [ ] Arabic/English and RTL tested
- [ ] Responsive/accessibility tests recorded
- [ ] Static assets and CSP checked
- [ ] Repository and deployment disclosure review complete
- [ ] Legal/IP pre-publication review complete
- [ ] Agent council pilot evidence available
- [ ] LS-PDC-001 requirements approved
- [ ] Owner explicitly authorized publication

Nothing is marked complete without supporting evidence.
